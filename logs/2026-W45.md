### 9:00PM

Using `New-ADOrganizationalUnit`, I added a new OU to my Guilds, "CollegeOfWinterhold". It was added under the Guilds OU, which is under the Skyrim OU, in the lab DC, in the local DC. Yay.

Command: `New-ADOrganizationalUnit -Name "CollegeOfWinterhold" -Path "OU=Guilds,OU=Skyrim,DC=lab,DC=local" -ProtectedFromAccidentalDeletion $false`

Putting the command into a `foreach` loop, I added the remaining 3 guilds. The loop iterates over the strings denoted as $g, adding them into the Guilds OU as well.

Command: 
```
foreach ($g in "ThievesGuild","DarkBrotherhood","Blades") {
    New-ADOrganizationalUnit -Name $g -Path "OU=Guilds,OU=Skyrim,DC=lab,DC=local" -ProtectedFromAccidentalDeletion $false
}
```

### 8:40PM

I've added some Global groups, alongside Domain Local ones.

Command:
```
foreach ($g in "GG_ThievesGuild","GG_DarkBrotherhood","GG_Blades") {
    New-ADGroup -Name $g -GroupScope Global -GroupCategory Security -Path "OU=Groups,OU=Skyrim,DC=lab,DC=local"
}
```
Command:
```
foreach ($g in "DL_Share_ArcaneArchives_RW", "DL_Share_ArcaneArchives_RO", "DL_Share_ThievesStash_RW", "DL_Share_SanctuaryContracts_RW", "DL_Share_BladesIntel_RW") {
    New-ADGroup -Name $g -GroupScope DomainLocal -GroupCategory Security -Path "OU=Groups,OU=Skyrim,DC=lab,DC=local"
}
```

I did run into the following error which puzzled me:

<img width="1170" height="163" alt="image" src="https://github.com/user-attachments/assets/11e2380a-0b7b-4fa7-86cc-e463a62307f2" />

However, it was simply just putting all my strings in one big quotes (i.e. "kind of like this" rather than "kind", "of", "like", "this") bracket. Giving each string its own individual quotes fixed the issue.

Category decides whether a group can hold permissions (Security) or is just a mailing list (Distribution). Scope decides where the group can be used and what it can contain (Global for people, Domain Local for resource access).

<summary><h1>Friday, Nov 6</h1></summary>

Ran the following command to set a lab password for the users:

`$pw = Read-Host "Lab password" -AsSecureString`

Then added a user Farkas Wolf using a command rather than GUI:

```New-ADUser -Name "Farkas Wolf" -GivenName "Farkas" -Surname "Wolf" -SamAccountName "farkas" -UserPrincipalName "farkas@lab.local" -Department "Companions" -Path "OU=Companions,OU=Guilds,OU=Skyrim,DC=lab,DC=local" -AccountPassword $pw -Enabled $true```

Then added him to a group:

```Add-ADGroupMember -Identity "GG_Companions" -Members "farkas"```
