Now, I will use the following loop to add a bunch of users

```
foreach ($u in $users) {
    $params = @{
        Name              = "$($u.First) $($u.Last)"
        GivenName         = $u.First
        Surname           = $u.Last
        SamAccountName    = $u.Sam
        UserPrincipalName = "$($u.Sam)@lab.local"
        Department        = $u.Guild
        Path              = "OU=$($u.Guild),OU=Guilds,OU=Skyrim,DC=lab,DC=local"
        AccountPassword   = $pw
        Enabled           = $true
    }
    New-ADUser @params
    Add-ADGroupMember -Identity "GG_$($u.Guild)" -Members $u.Sam
}

```

Just an example of some users added to their guild correctly.

#### Now, I will use a nesting command to add members of the Global Groups into Domain Local ones.

`Add-ADGroupMember -Identity "DL_Share_Jorrvaskr_RW" -Members "GG_Companions"`

What this does is adds the "members" of "GG_Companions", the global security group, and adds them to the "DL" domain local group.

Global groups collect people, and DL groups give them permissions.

<img width="385" height="146" alt="image" src="https://github.com/user-attachments/assets/839a1de1-9134-4efc-9b20-2f00cf378f46" />

#### Now, you can see the GG Companions has been added as a "Member Of" my domain local group, Jorrvaskr. Any user who is a member of my Companions group will have the permissions granted by the Jorrvaskr DL group.

I have also done the same for the rest of the global groups with the follow set of commands:

```
Add-ADGroupMember -Identity "DL_Share_ArcaneArchives_RW"   -Members "GG_CollegeOfWinterhold"
Add-ADGroupMember -Identity "DL_Share_ArcaneArchives_RO"   -Members "GG_Blades","GG_Companions"
```
